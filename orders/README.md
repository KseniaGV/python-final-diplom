# Backend-приложение для автоматизации закупок

Дипломный проект по профессии «Python-разработчик: расширенный курс» от Нетологии.

## Описание проекта

Backend-приложение для автоматизации закупок в розничной сети. Сервис позволяет работать с товарами от нескольких поставщиков, управлять каталогом товаров и заказами через REST API.

Проект разработан на Django и Django REST Framework.

## Стек

- Python 3.10+
- Django
- Django REST Framework
- SQLite
- PyYAML
- Requests
- Git

## Реализованный функционал

На текущий момент реализованы:

- Кастомная модель пользователя на основе AbstractUser.
- Разделение пользователей на покупателей и поставщиков.
- Модели магазинов, категорий, товаров и характеристик.
- Модели заказов, позиций заказа и контактных данных.
- Импорт товаров из YAML-файлов поставщиков.
- Обновление прайса поставщика через API.
- Регистрация пользователей.
- Подтверждение регистрации по электронной почте.
- Авторизация пользователей с использованием токенов.
- Django Admin для управления моделями и просмотра данных.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <адрес-вашего-репозитория>
```

Перейдите в папку проекта:

```bash
cd orders
```

### 2. Создание виртуального окружения

```bash
python -m venv env
```

### 3. Активация виртуального окружения

Для Windows Git Bash:

```bash
source env/Scripts/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Создание администратора

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000/

Панель администратора:

http://127.0.0.1:8000/admin/

## API Endpoints

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/partner/update/` | Импорт и обновление прайса поставщика |
| POST | `/user/register/` | Регистрация пользователя |
| POST | `/user/register/confirm/` | Подтверждение электронной почты |
| POST | `/user/login/` | Авторизация пользователя |

### Импорт товаров

Для обновления прайса поставщик отправляет POST-запрос:

```json
{
    "url": "https://raw.githubusercontent.com/netology-code/python-final-diplom/master/data/shop1.yaml"
}
```

Запрос выполняется по адресу:

```text
POST /partner/update/
```

Для выполнения запроса необходима авторизация пользователя с типом `shop`.

### Регистрация

Пример запроса:

```json
{
    "first_name": "Тест",
    "last_name": "Покупатель",
    "email": "buyer@test.ru",
    "password": "Test12345!"
}
```

После регистрации пользователю отправляется письмо с токеном подтверждения.

### Подтверждение электронной почты

Для подтверждения регистрации необходимо отправить:

```json
{
    "email": "buyer@test.ru",
    "token": "YOUR_CONFIRMATION_TOKEN"
}
```

### Авторизация

Пример запроса:

```json
{
    "email": "buyer@test.ru",
    "password": "Test12345!"
}
```

При успешной авторизации API возвращает токен пользователя.

## Электронная почта

Для разработки используется консольный backend Django:

```python
EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
```

Письма выводятся в терминал, в котором запущен сервер.

Для отправки настоящих электронных писем необходимо настроить SMTP.
