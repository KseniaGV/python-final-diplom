# Backend-приложение для автоматизации закупок

Дипломный проект по профессии «Python-разработчик: расширенный курс».

## Описание проекта

Backend-приложение для автоматизации закупок в розничной сети. Сервис позволяет покупателям работать с каталогом товаров от нескольких поставщиков, формировать корзину, оформлять заказы и отслеживать их статусы.

Поставщики могут загружать и обновлять прайсы, а администратор — управлять данными и заказами через панель Django Admin.

Проект разработан на Django и Django REST Framework с использованием REST API.

## Реализованный функционал

### Пользователи и авторизация
- Кастомная модель пользователя на основе AbstractUser.
- Разделение пользователей на покупателей и поставщиков.
- Регистрация пользователей.
- Подтверждение регистрации по электронной почте.
- Авторизация с использованием токенов DRF.
- Разграничение доступа в зависимости от типа пользователя.

### Каталог товаров
- Получение списка товаров.
- Просмотр подробной информации о товаре.
- Фильтрация товаров по магазину и категории.
- Поиск товаров по названию, модели и магазину.
- Получение характеристик товаров.

### Поставщики
- Импорт товаров из YAML-файлов.
- Обновление прайса поставщика через API.
- Создание и обновление информации о товарах, категориях и характеристиках.

### Корзина
- Просмотр содержимого корзины.
- Добавление товаров в корзину.
- Изменение количества товаров.
- Удаление товаров из корзины.
- Проверка доступного количества товаров.
- Сохранение цены товара на момент добавления в корзину.

### Контактные данные
- Добавление и просмотр контактных данных.
- Поддержка одного телефонного номера.
- Возможность добавления до пяти адресов доставки.
- Удаление контактных данных.

### Заказы
- Оформление заказа на основе содержимого корзины.
- Проверка принадлежности адреса покупателю.
- Проверка наличия товаров в необходимом количестве.
- Получение списка заказов пользователя.
- Отображение состава заказа и его статуса.
- Изменение статуса заказа поставщиком.
- Отправка уведомлений покупателю при изменении статуса заказа.

### Электронная почта
- Отправка письма после регистрации.
- Уведомление покупателя и администратора при оформлении заказа.
- Уведомление покупателя при изменении статуса заказа.
- Использование консольного backend Django для разработки.

### Администрирование
- Django Admin для управления моделями и данными.
- Просмотр заказов и их состава.
- Фильтрация заказов по статусу и дате.
- Поиск заказов по электронной почте покупателя.
- Изменение статусов заказов с отправкой уведомлений.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <адрес-вашего-репозитория>
```

Перейдите в папку проекта:

```bash
cd orders
```

### 2. Создание виртуального окружения

```bash
python -m venv env
```

### 3. Активация виртуального окружения

Для Windows:

```bash
env\Scripts\activate
```

Для Linux и macOS:

```bash
source env/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Применение миграций

```bash
python manage.py migrate
```

### 6. Создание администратора

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000/
```

Панель администратора:

```text
http://127.0.0.1:8000/admin/
```

## API Endpoints

Все запросы выполняются относительно базового адреса:

```text
http://127.0.0.1:8000/
```

### Пользователи

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/user/register/` | Регистрация пользователя |
| POST | `/user/register/confirm/` | Подтверждение электронной почты |
| POST | `/user/login/` | Авторизация пользователя |

### Каталог товаров

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/products/` | Получение списка товаров |
| GET | `/products/<product_info_id>/` | Получение информации о товаре |

Поддерживаемые параметры фильтрации:

- `shop_id` — фильтрация по магазину.
- `category_id` — фильтрация по категории.
- `search` — поиск по названию товара, модели или магазину.

Пример:

```text
GET /products/?category_id=1&search=Apple
```

### Поставщики

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/partner/update/` | Импорт и обновление прайса поставщика |

Для обновления прайса поставщик отправляет POST-запрос:

```json
{
    "url": "https://raw.githubusercontent.com/netology-code/python-final-diplom/master/data/shop1.yaml"
}
```

Для выполнения запроса необходима авторизация пользователя с типом `shop`.

### Корзина

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/basket/` | Просмотр корзины |
| POST | `/basket/add/` | Добавление товара в корзину |
| PATCH | `/basket/update/<item_id>/` | Изменение количества товара |
| DELETE | `/basket/remove/<item_id>/` | Удаление товара из корзины |

Пример добавления товара:

```json
{
    "product_info_id": 1,
    "quantity": 2
}
```

Пример изменения количества:

```json
{
    "quantity": 3
}
```

### Контактные данные

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/contacts/` | Получение контактных данных |
| POST | `/contacts/add/` | Добавление контакта |
| DELETE | `/contacts/remove/<contact_id>/` | Удаление контакта |

Пример добавления адреса:

```json
{
    "type": "address",
    "value": "Москва, ул. Тестовая, д. 10, кв. 5"
}
```

Для добавления телефона используется значение `phone` в поле `type`.

### Заказы

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/orders/create/` | Оформление заказа |
| GET | `/orders/` | Получение списка заказов пользователя |
| PATCH | `/orders/<order_id>/status/` | Изменение статуса заказа |

Пример оформления заказа:

```json
{
    "contact_id": 1
}
```

Пример изменения статуса заказа:

```json
{
    "status": "confirmed"
}
```

Доступные статусы заказа:

- `basket` — корзина.
- `new` — новый.
- `confirmed` — подтверждён.
- `assembled` — собран.
- `sent` — отправлен.
- `delivered` — доставлен.
- `canceled` — отменён.

Для работы с защищёнными endpoint необходимо передавать токен авторизации в заголовке:

```text
Authorization: Token YOUR_AUTH_TOKEN
```

## Электронная почта

Для разработки используется консольный backend Django:

```python
EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'
```

Письма выводятся в терминал, в котором запущен сервер.

В проекте предусмотрены уведомления:

- При регистрации пользователя отправляется письмо с токеном подтверждения.
- При оформлении заказа отправляются письма покупателю и администратору.
- При изменении статуса заказа покупатель получает уведомление.

Для отправки настоящих электронных писем необходимо настроить SMTP.
